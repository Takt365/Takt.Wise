# 空行格式（强制）

完整规范：`.cursor/rules/03-format-blank-lines.mdc`

**违反视为未完成修改，不得交付。**

## 禁止（❌）

1. **隔行空行**：一行代码/注释 + 一行空白交替（行数约 ×2）
2. **连续 2+ 空行**
3. **文件头前空行**；属性与 `SugarColumn`/XML 注释之间空行

## 允许（✅）

| 场景 | 最多 |
|------|------|
| using 与 namespace 之间 | 1 行 |
| 文件头块与 using 之间 | 1 行 |
| 相邻类型/成员之间 | 1 行 |
| 逻辑段落（#region 等） | 1 行 |

## 写入后自检清单

```
- [ ] 无「有效行 + 空白行」交替
- [ ] 无连续空白行 ≥2
- [ ] 与同目录参照文件密度接近（TaktUser.cs、user.ts）
- [ ] 仅改格式时不改业务逻辑
```

## 参照密度

| 语言 | 参照 |
|------|------|
| C# | `TaktUser.cs`、`TaktCultureSeedData.cs` |
| TS | `api/identity/user.api.ts` |
| Vue | 同目录已有 CRUD 页 |

## 修复流程

1. 删除属性/注释之间的多余空行（XML 三行与属性应紧挨）
2. 合并连续空行为单行
3. 删除文件首行空白
4. 目视：任意相邻两行不能都是空白

## Agent 约束

- **写入前**按紧凑格式生成，禁止工具输出隔行空行
- **批量替换后**必须跑一遍本清单
- 发现行数约为有效行数 2 倍 → 立即重写排版
